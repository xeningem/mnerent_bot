# Поиск квартиры в Баре

Открытый Telegram-бот и сборщик на Python для поиска долгосрочной аренды в Черногории. У каждого пользователя свои фильтры, которые настраиваются кнопками. По умолчанию: любой город, до 800 €/месяц, от двух спален, аренда на весь год.

## Что работает

- Чтение текстов и подписей из шести источников через пользовательскую сессию Telegram, без отправки сообщений авторам и без автоматического вступления в группы.
- Однократная загрузка последних 14 дней, затем чтение новых сообщений каждые 10 минут и проверка последних 3 дней раз в 6 часов. После простоя или ошибки источника окно автоматически расширяется. Редактирование постов в пределах окна обновляет запись и присылает пост снова.
- Для каждого поста сохраняются автор (ID, имя, username) и скрытые ссылки: адреса под словами, скрытые упоминания и кнопки со ссылками.
- Консервативный разбор русского и некоторых сербских/английских формулировок: цена, спальни, район, годовые/сезонные условия.
- SQLite, точная дедупликация нормализованного текста, уведомления о новых кандидатах и изменениях текста.
- Открытый бот: пользоваться может любой, первое сообщение регистрирует пользователя. У каждого свои фильтры, страницы, скрытие и пауза. Владелец (`OWNER_ID`) видит статистику и может заблокировать пользователя.
- Настройка кнопками: при первом `/start` три шага (город, бюджет, спальни), уведомления включаются после их завершения. Затем все фильтры меняются через `/filters`.
- Первая историческая загрузка доступна через /find, без массовой рассылки. Новый пользователь и пользователь, сменивший фильтр, получают уведомления только о новых и изменённых постах, а остальное видят через /find.

## Быстрый запуск на Mac / Linux с Docker

1. Распакуй архив и открой терминал в папке `bar-rent`.
2. Создай приложение на https://my.telegram.org → API development tools. Сохрани `api_id` и `api_hash`.
3. В Telegram открой https://t.me/BotFather → `/newbot`. Сохрани токен бота.
4. `OWNER_ID` пока можно оставить пустым: команда `login` ниже покажет твой числовой ID. После авторизации впиши его в `.env`.
5. Скопируй конфигурацию:

```bash
cp .env.example .env
chmod 600 .env
```

Заполни `TG_API_ID`, `TG_API_HASH`, `BOT_TOKEN`, `OWNER_ID` в `.env` локально. Не присылай токены, коды входа или файл сессии в чат.

6. Выполни авторизацию в терминале (номер телефона, код Telegram, пароль 2FA при наличии):

```bash
docker compose build
docker compose run --rm bot python app.py login
```

7. При необходимости проверь сбор до включения бота:

```bash
docker compose run --rm bot python app.py scan
docker compose run --rm bot python app.py export > candidates.json
```

8. Запусти сервис:

```bash
docker compose up -d
docker compose logs -f
```

Открой своего бота и отправь `/start`, затем `/find` и `/status`.

Остановить:

```bash
docker compose down
```

Компьютер должен оставаться включённым и подключённым к интернету. Для непрерывной работы проект можно перенести на VPS вместе с `.env` и `data/` по защищённому каналу. Две копии сборщика с одной сессией одновременно не запускай.

## Без Docker

Python 3.11+:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Заполни .env
python app.py login
python app.py scan
python app.py run
```

На Python ниже 3.11 проект не проверялся в реальной работе.

Параметры: `python app.py run --days 14 --interval 600 --rescan-days 3 --deep-hours 6`. Окно истории и выдачи `/find` задаётся `--days`, интервал в секундах — `--interval` (минимум 60). На каждом проходе читаются только новые сообщения. Раз в `--deep-hours` часов перечитывается окно `--rescan-days` дней, чтобы заметить правки старых постов. Бот отвечает сразу после запуска, сбор идёт в фоне: при первом запуске `/find` покажет только уже собранное.

Для настройки фильтра: `python app.py export --all > all.json` выгружает и отклонённые посты с причинами, `python app.py reparse` пересчитывает уже собранные записи после изменения парсера.

## Команды бота

- `/start` — настройка при первом запуске, затем меню фильтров и справка.
- `/filters` — меню фильтров: значение меняется нажатием на кнопку, сверху видно, сколько объявлений подходит.
- `/find` — первая страница подходящих объявлений (по умолчанию 5, в фильтрах можно выбрать до 50), свежие сначала.
- `/more` — следующая страница.
- `/file` — все подходящие объявления одним HTML-файлом (документом в чате): цена, район, спальни, срок, ссылка на пост, текст раскрывается по клику. В файле есть панель: поиск по тексту, сортировка (новые, дешевле, дороже, больше спален), фильтры по району и сроку, «Только ★» и «Развернуть все». Открывать лучше в браузере (Safari, Chrome): во встроенном просмотрщике Telegram скрипты могут не работать, тогда панели не будет, но список и ссылки останутся. Избранное всегда попадает в файл, даже если не подходит под фильтры.
- `/favorites` — избранное. На карточке кнопка «☆ В избранное» (повторное нажатие убирает). Отметка личная и не зависит от «Скрыть» и фильтров.
- `/status` — время последнего сканирования каждого источника и ошибка, если есть. Время в UTC.
- `/pause`, `/resume` — остановить/возобновить уведомления. Поиск продолжает работать.
- «Скрыть» — скрывает эту публикацию только для тебя; кнопка сразу меняется на «Вернуть».
- Только для владельца: `/users` — статистика (всего, завершили настройку, с уведомлениями, новые за 7 дней, заблокированные, выбранные города), `/deny <ID>` — заблокировать, `/allow <ID>` — разблокировать.

## Повторы и похожие объявления

Некоторые авторы публикуют одно и то же снова и снова, поэтому в выдаче остаётся самая свежая копия, а в карточке под текстом поста, перед ссылкой, видно: «повторов: 10, впервые 2026-10-24». Если у того же автора есть почти такой же пост с другой ценой, там же появляется строка «Похожее #16701 (2026-10-26): 498 € → 350 € (-148)» (от старого к новому). Это подсказка: так же выглядят и разные квартиры одного шаблона. Если более старый похожий пост был дороже, такое объявление идёт первым в `/find` и в файле `/file` (в файле порядок можно сменить). Смена эмодзи в тексте не считается отличием.

## Фильтры

- **Город:** один или несколько. Если город выбран, пост без города скрывается: большинство источников охватывают всю страну.
- **Цена:** готовые варианты, своя сумма или без предела.
- **Спальни:** от 1, 2, 3 или любое число.
- **Район:** есть для Бара, Будвы, Тивата, Котора, Подгорицы, Херцег-Нови и Ульциня. Выбор сужает только свой город; пост без района остаётся.
- **Срок:** кнопка переключает три режима. «Год» скрывает посты с явными сезонными признаками, а посты без указания срока оставляет. «Сезон» показывает только посты с явными сезонными признаками. «Любой» показывает всё. В заголовке карточки стоит «срок: год», «срок: сезон» или «срок: ?». Посуточная аренда скрыта у всех.
- **Неполные объявления:** показывать или скрывать посты без цены или числа спален.
- **Скрытые:** режим «показывать» добавляет в `/find` скрытые тобой посты с кнопкой «Вернуть». В уведомления они не попадают.
- **Слова:** все обязательные должны быть в тексте, запрещённых быть не должно. Слово совпадает с окончанием до трёх букв: «кот» найдёт «котом», но не «который».

Без явного значения пост не отклоняется по цене, спальням и району. После смены фильтра уведомления приходят только о новых постах, старые подходящие показывает `/find`.

## Резервная копия

Git хранит код, но не `data/` и `.env`. Состояние бота (база, отметки пользователей, сессия Telegram) копирует скрипт:

```bash
scripts/backup.sh              # в ~/Backups/mnerent_bot/<дата-время>, хранятся 14 последних
scripts/backup.sh /путь        # другой каталог; KEEP=30 меняет число копий
```

Работает при запущенном боте (используется `sqlite3 .backup`). Нужен `sqlite3`. Внутри токены и сессия аккаунта, поэтому права `700`; не публикуй каталог копий. Для регулярного запуска добавь строку в `crontab -e`, например `0 4 * * * /путь/к/проекту/scripts/backup.sh`.

## Ограничения первой версии

Это рабочий каркас с проверенным локально фильтром, а не уже подключённый сервис. Без пользовательской авторизации Telegram и токена бота реальный сбор и доставка не проверены.

Парсер намеренно не объявляет квартиру подходящей автоматически: даже явное «с декабря» требует проверки года и доступности. Поэтому все неотклонённые варианты идут в «нужно уточнить». Объявления без района/цены/спален тоже попадают туда.

У всех отклоняются: сообщения без признаков аренды, вопросы и запросы «сниму», продажа без упоминания аренды, посуточная аренда без упоминания долгосрочной и нежилые объекты. В группе `realestate_bar` Бар подразумевается, если не назван другой город. Пост с несколькими городами или с продажей остаётся с пометкой: это может быть список районов или подпись агентства. Из-за этих правил объявление без слов об аренде будет потеряно, а без названия города — скрыто у тех, кто выбрал город; проверять такие потери можно через `export --all`.

Текст «2 комнаты» и `dvosoban`/`trosoban` не считаются числом спален. Несколько разных сумм в EUR считаются неоднозначной ценой; если даже меньшая выше предела цены пользователя, пост отклоняется. «Долгосрочно» не считается гарантией аренды на весь год. Депозит, комиссия и коммунальные расходы показываются в исходном тексте, но отдельно не извлекаются. Для сложных текстов следующим шагом можно добавить LLM со структурированной схемой и доказательствами из исходника.

Дубли объединяются только при совпадении нормализованного текста. Разные описания одной квартиры пока будут отдельными карточками; скрытие одного поста не скрывает все возможные дубли. Фотографии доступны по ссылке на оригинал, отдельно бот их пока не пересылает. Альбомы без текстовой подписи не анализируются. Удаления постов не отслеживаются, исчезнувшие квартиры не помечаются автоматически сданными. Через 14 дней (`--days`) после публикации пост выпадает из выдачи.

Обновление текста вызывает уведомление, если пост остаётся кандидатом; отдельного сравнения старой и новой цены пока нет. Доставка с повтором при сбоях; в редком случае падения после отправки, до записи в SQLite, возможен повтор уведомления. Пакеты имеют ограничение основных версий; для воспроизводимого production-развёртывания стоит зафиксировать lock-файл в целевой среде.

Файл `data/reader.session` даёт доступ к Telegram-аккаунту. Он и `.env` должны оставаться приватными. В архиве их нет. Исходящие операции пользовательского аккаунта не используются. Запросы пользователей обслуживаются только через Bot API из базы и не обращаются к Telegram от имени личного аккаунта. Карточки с именами и username авторов видит любой пользователь бота.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты покрывают бюджет и разбор цены, сезонность, подсчёт спален, сербские формулировки, отсев переписки и нежилых объявлений, географию, окно сканирования, обновление записей, дедупликацию и скрытие.
